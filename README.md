## 📖 项目简介

**SocksWPE** 是一款运行在 Windows 平台的高性能网络代理与封包处理工具，把 **SOCKS5 代理服务**、**WPE 风格封包滤镜引擎**、**SSL 中间人解密**、**AntiCC 防护** 和 **多实例管理** 融合在一个程序里。

底层采用 **IOCP（完成端口）线程池**扛高并发，界面基于 **WebView2** 用现代 Web 技术渲染，配置与数据用 **SQLite** 持久化，支持**云端授权与配置下发**。

一句话：**收得到、改得动、扛得住、管得多。**

## ✨ 核心功能

### 🧩 WPE 封包滤镜引擎（核心）
项目的灵魂模块，对经过代理的数据包做实时搜索与修改：

- **两种模式**：普通模式（Normal）/ 高级模式（Advanced）
- **多种动作**：替换（Replace）、拦截（Intercept）、显示不改、不改不显、生成新包（Change）
- **十六进制模式匹配**：支持 `位置|字节` 格式、通配符（`??`）、掩码匹配
- **条件触发**：按包头特征、包长度范围、端口精确命中
- **随机化 & 递增**：指定位置随机取值，或按步长自动递增（支持进位、连续递增）
- **高级开关**：命中某特征时自动启用/禁用滤镜（触发式开关）
- **方向控制**：可分别作用于请求（上行）/ 响应（下行）
- **执行优先级**：支持多规则排序，可上移/下移/置顶/置底
- **导入导出**：滤镜规则可导出 JSON、合并导入、覆盖导入

### 🛡️ AntiCC 防护
面向代理入口的抗攻击 / 滥用防护：

- **IP 信任评分系统**（0–100，带缓存）
- **黑名单 / 白名单**（白名单带有效期、12 小时自动清理）
- **滑动时间窗口限流** + **速率限制**（请求/秒）
- **认证失败封禁**、**无认证封禁**、**最大连接数限制**
- **防火墙联动**：可下发防火墙规则、拦截非 SOCKS5 连接
- **全局协调器（GlobalAntiCCCoordinator）**：多实例统一防护策略

### 🔓 SSL 中间人解密（SSLMitmContext）
- 基于 Windows **SChannel** 实现的 SSL/TLS MITM
- 支持**按端口**或**按域名**（含 `*` 前缀通配）匹配解密目标
- 动态签发服务端证书，解密后可交给滤镜引擎处理

### 🗂️ 多实例管理（InstanceManager）
一个程序同时跑多个独立实例：

| 类型 | 说明 |
|------|------|
| **SOCKS5 账号库** | 多账号池化管理 |
| **SOCKS 转发** | 支持 WPE 滤镜 + 二级代理 |

每个实例独立配置、独立状态机（停止/启动中/运行/停止中/错误）。

### 👤 用户级滤镜授权（UserFilterManager）
- 每个 SOCKS 账号可绑定**独立的滤镜配置和滤镜组**
- 区分「未配置」与「配置为空」
- 授权滤镜 / 默认启用 / 用户启用三级生效逻辑

### ☁️ 云端集成（CloudIntegration）
- **云端授权 / 卡密验证**（账号模式 + 卡密模式双登录）
- **配置下发**：策略、AntiCC 配置、WPE 滤镜规则、SOCKS 账号
- **远程许可**：启停实例、应用运行时配置、导出快照均可云端授权
- **上报**：事件上报、指标上报

### 🖥️ 界面与接口
- **WebView2 现代化 UI**：`web/` 目录下 HTML/CSS/JS 前端
- **HTTP API 服务器**：对外提供接口
- **TCP 文件传输**：内置文件收发服务
- **断网规则引擎（DisconnectRuleEngine）**：按规则触发断连

## 🚀 编译构建

**环境要求**
- Windows 10/11
- Visual Studio 2022（含 C++ 桌面开发工作负载，v143）
- 已包含 WebView2 / WIL 依赖包（`packages/` 已随仓库提供，无需额外还原）

**步骤**
```
1. 用 Visual Studio 2022 打开 新伪心跳.sln
2. 选择配置：Release | x64（或 Debug / Win32）
3. 生成 → 生成解决方案（F7）
4. 输出在 x64/Release/ 下
```

> 仓库已内置 WebView2 + WIL 的 NuGet 包，克隆后可直接编译，不需要联网还原依赖。
